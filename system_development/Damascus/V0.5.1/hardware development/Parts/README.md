# Parts

## Base ring

- The original base ring did not provide enough clearance between the camera lenses and the glass with the current camera mounts.
- Moving the cameras back would require more involved changes because the camera cables were already against the cap.
- [SealedGlassRing_Lowered.ipt](SealedGlassRing_Lowered.ipt) lowers the glass seat to provide additional lens clearance.
- [Adapter_LoweredRing.ipt](Adapter_LoweredRing.ipt) holds the O-ring above the glass, retaining the intended seal arrangement.
- The lowered ring and adapter were printed in ABS-GF, and the cameras and glass fit without interference.
- As agreed on October 30, 2026, we will keep both the original and lowered base rings for preliminary testing and revisit larger design changes later.
